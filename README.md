# OZ Marketplace 🛒

e-commerce marketplace for fast delviery system and for efficient variety of clothing , last resort for fashion fast delivery fills the gap of stores and customer , which will help students or others to get there dress before time and can attend any event or shoping or any planning mm.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Key Features

- **Dynamic Product Catalog**: 29+ curated categories with rich fashion imagery and high-density product grids.
- **Smart Delivery Location**: Location selector with geocoding, pincode search, and saved addresses.
- **Interactive UI**: Drag-to-scroll category carousel, quick add-to-cart, and instant wishlist management.
