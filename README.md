# OZ Marketplace 🛒

A luxury fashion & e-commerce marketplace web application built with Next.js 16, React 19, TypeScript, and Tailwind CSS.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Key Features

- **Dynamic Product Catalog**: 29+ curated categories with rich fashion imagery and high-density product grids.
- **Smart Delivery Location**: Location selector with geocoding, pincode search, and saved addresses.
- **Interactive UI**: Drag-to-scroll category carousel, quick add-to-cart, and instant wishlist management.
